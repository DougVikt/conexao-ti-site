Posts do Instagram (com legenda ocultada via parâmetros oficiais)\n2. Posts do LinkedIn (página oficial e grupo de membros) sem chaves de autenticação\n3. Seção \"Biblioteca\" que exibe dinamicamente pastas e arquivos do Google Drive para download direto\n\n## Contexto\nO projeto atualmente possui:\n- Integração parcial com Google Drive via API (requer config.js com API key e ID da pasta)\n- Tentativa quebrada de exibir posts do Instagram após modificação para truncar legenda\n- Exibição estática de links para LinkedIn (não mostra posts reais)\n- Falta de atualização automática da biblioteca ao adicionar novos arquivos no Drive\n\n## Análise do Estado Atual\n\n### 1. Instagram Embed (Quebrado)\n**O que está quebrado:**\n- A função `fetchInstagramOEmbed` em `main/js/data.js` não realiza a chamada à API de oEmbed. Ela contém código de conversão de timestamp que não pertence a essa função e não retorna o HTML do embed.\n- Como resultado, o feed do Instagram não carrega e cai para o fallback estático.\n\n**O que deveria funcionar (com base na pesquisa):**\n- A API do Instagram oEmbed agora funciona **sem token de acesso** para conteúdo público via Facebook Graph API.\n- Endpoint correto: `GET https://graph.facebook.com/v26.0/instagram_oembed?url={POST_URL}&hidecaption=true&maxwidth=658`\n- Parâmetro `hidecaption=true` oculta completamente a legenda, resolvendo o problema de truncamento.\n- O HTML retornado contém tudo necessário para renderização (blockquote + script).\n\n### 2. LinkedIn Embed (Parcialmente Funcional)\n**O que funciona:**\n- Embeds individuais de posts públicos do LinkedIn via iframe funcionam quando o post é público (ícone do globo).\n- O projeto já possui exemplos de embeds individuais no array `FEATURED_POSTS`.\n\n**O que não funciona ou é limitado:**\n- Não existe endpoint público oEmbed para LinkedIn que permita buscar feeds sem autenticação.\n- O embed de grupo (usando `urn:li:group:`) não é oficial e pode não funcionar de forma confiável.\n- Os embeds são estáticos: não atualizam automaticamente com novos posts.\n- Se o post original for excluído ou tornar-se privado, o embed mostra caixa vazia.\n\n### 3. Google Drive Biblioteca (Parcialmente Funcional)\n**O que funciona:**\n- A integração com Google Drive está parcialmente implementada e funciona quando `config.js` contém `apiKey` válido e `parentFolderId` correto.\n- Funções existentes: `fetchFoldersFromDrive()`, `getFileCountMap()`, `initializeDriveFolders()`.\n- O evento `drive-data-loaded` é disparado e `biblioteca.html` possui listener para renderizar a grade.\n\n**O que está faltando ou quebrado:**\n- `biblioteca.html`.renderiza apenas os nomes das pastas e a contagem de arquivos, mas **não lista os arquivos dentro de cada pasta**.\n- A função `fetchFoldersFromDrive` em `data.js` já retorna um array de pastas onde cada pasta tem uma propriedade `files` contendo os objetos de arquivo, mas esse dado não é utilizado no renderer.\n- Os links para pastas apontam para a pasta no Drive, mas não há links diretos para os arquivos individuais.\n- Se `config.js` não tiver credenciais válidas, cai para fallback estático (que também não lista arquivos dentro das pastas).\n\n## Requisitos Funcionais\n\n### Instagram\n| ID | Requisito | Prioridade | Observações |\n|----|-----------|------------|-------------|\n| IG-1 |
